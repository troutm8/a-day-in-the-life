# A Day in the Life - Text Adventure Game

A simple choose-your-own-adventure game where you navigate through a morning routine with randomly assigned conditions.

## Features

- Random day assignment (workday or weekend)
- Multiple choice-based paths
- Different endings based on your decisions
- Typewriter effect for immersive text display
- Clean terminal-based interface

## How to Play

### On MacOS/Linux:

1. Open Terminal
2. Navigate to this directory:
   ```bash
   cd /path/to/a-day-in-the-life
   ```
3. Run the game:
   ```bash
   python3 adventure.py
   ```
   or
   ```bash
   ./adventure.py
   ```

### Game Controls

- When presented with choices, type the number of your choice (1, 2, or 3)
- Press Enter to submit your choice
- Press Ctrl+C at any time to quit the game

## Game Structure

The game starts with you waking up in the morning. The game randomly decides whether it's a workday or weekend, which affects:
- The scenarios you encounter
- The choices available to you
- The possible endings

Each playthrough is different, so try playing multiple times to see all the possible outcomes!

## Expanding the Game

This is a simple starter version. You can easily expand it by:
- Adding more scenes and choices
- Creating longer story paths
- Adding an inventory system
- Including character stats or health
- Adding save/load functionality
- Creating more complex branching narratives

## Requirements

- Python 3.x (pre-installed on MacOS)

Enjoy your adventure!
